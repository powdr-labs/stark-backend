# 2026-04-13-1600-batch-round0-descriptor-arrays

Replace per-AIR Round 0 kernel launches with batched descriptor-array kernels for both zerocheck constraint evaluation and logup interaction evaluation. Currently, each of the ~310 AIRs per segment at APC 300 gets 2+ individual kernel launches, buffer allocations, and H2D copies, resulting in ~1500 kernel launches per segment — nsys profiling shows 76% of Round 0 wall time (294ms) is overhead, not GPU compute. By caching the interaction DAG structure at keygen and batching all per-AIR contexts into a single H2D upload + single kernel launch (using the proven descriptor-array pattern from MLE batch kernels), we expect to reduce Round 0 from 294ms to ~100ms at APC 300, saving ~190ms from STARK excl trace.
