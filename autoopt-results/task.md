# 2026-04-13-2200-prealloc-round0-threshold-buffers

Pre-allocate per-thread reusable GPU buffers for Round 0 constraint and interaction evaluation using an adaptive size threshold, rather than pre-allocating for the maximum AIR size. The previous pre-allocation attempt (prealloc-round0-buffers) failed because it pre-allocated for the largest AIR's intermediates (~1GB per thread × 8 threads = 8GB), causing systemic GPU memory pressure that degraded all phases. The adaptive approach pre-allocates buffers sized for the Nth-percentile AIR (e.g., 95th percentile), covering 95%+ of AIRs while keeping total allocation manageable. Small/medium AIRs (the vast majority at APC 300) skip the global MEMORY_MANAGER mutex entirely, while the few large AIRs fall back to dynamic allocation. This addresses the same root cause as the successful GKR pre-alloc optimization (which saved 217ms): eliminating per-AIR mutex contention and cudaMallocAsync/cudaFreeAsync serialization across 8 concurrent worker threads.
